# Home-Products
תוכנה לרכישה ומעקב למוצרים לבית חדש

**N°01 · קטלוג הדירה** — אפליקציית ווב בעברית לניהול כל הקניות לדירה חדשה: קטגוריות, מוצרים, מחירים, סה״כ לכל קטגוריה וסה״כ כולל, סינון ומיון, וסימון ✓ למה שכבר נרכש. הרשימה נשמרת בענן ומשותפת לכל מי שיש לו את קוד הדירה.

## מה יש בפנים
- **מתכנן דירה** — סוג דירה (רגילה, דירת גן עם שטח גינה, פנטהאוז עם מרפסת גג ודופלקס) וקומה; מספר חדרים עם ייעוד, מידות וסימון ממ״ד לכל חדר; שירותים/מקלחות/אמבטיות, מרפסת (שטח, מקורה, סגירה), אי מטבח, סוג מיזוג, מחסן, חניות ועמדות טעינה, חיות מחמד ורמת מחירים — ומקבלים רשימה מלאה עם מחירים משוערים. אפשר להריץ שוב ולהוסיף רק את מה שחסר.
- **קטגוריות ומוצרים** — הוספה, עריכה, מחיקה, שכפול, העברה בין קטגוריות, סידור מחדש וקיפול.
- **מחירים** — כמות × מחיר ליחידה, ואפשרות לרשום מחיר ששולם בפועל. תקציב יעד עם התראת חריגה.
- **סינון ומיון** — חיפוש, סטטוס (נותר/נרכש), קטגוריה, עדיפות; מיון לפי שם, מחיר, עדיפות וסטטוס.
- **שיתוף** — קוד דירה סודי / קישור שיתוף; סנכרון בין מכשירים עם מיזוג שינויים מקבילים.
- **גיבוי** — ייצוא לאקסל (CSV), גיבוי ושחזור JSON. עובד גם בלי רשת ומסתנכרן כשחוזרים.

## פיתוח
```bash
npm install
cp .env.example .env   # מלאו כתובת ומפתח publishable של Supabase
npm run dev
npm run build          # בדיקת טיפוסים + בנייה ל-dist/
```

## מסד הנתונים
הסכמה ב-`supabase/migrations/001_hp_homes.sql`: טבלה אחת `hp_homes` (מסמך JSON לכל דירה) ששדה הזיהוי שלה הוא `sha256` של קוד הדירה. אין גישה ישירה לטבלה (RLS בלי policies); הגישה רק דרך הפונקציות `hp_create_home`, `hp_load_home`, `hp_save_home` (עם בדיקת גרסה אופטימית).

## פריסה
`netlify.toml` מוגדר (`npm run build` → `dist`). בהגדרות האתר צריך להגדיר `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_KEY`.
